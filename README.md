# Smart Mirror with Face Recognition 🪞💡  

This project is a **graduation project** developed as part of our final year in **Computer Engineering**.  
It integrates **facial recognition** for authentication and interactive content display,  
demonstrating the potential of smart mirrors in various applications,  
from personal use to smart home automation.

## 🚀 Features  
✅ Facial recognition-based authentication  
✅ Interactive UI for personalized content  
✅ Real-time information display  
✅ Modular hardware design with a two-way mirror  
✅ Expandable for IoT and smart home integration  

## 🛠️ Technologies Used  
- **Hardware:** Two-way acrylic mirror, Display, Raspberry Pi 5  
- **Software:** Python, OpenCV, Flask, NumPy, and others libraries. chech app.py
